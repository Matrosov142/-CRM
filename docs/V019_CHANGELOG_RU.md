# ПОТОК CRM Pilot v0.19 — предварительная калькуляция позиции тендера

## Реализовано
- Добавлен калькулятор себестоимости одной позиции тендера.
- Компоненты на единицу товара: закупка, логистика, обработка, упаковка, налоги/сборы и прочие расходы.
- Три сценария цены: осторожный, целевой и агрессивный.
- Маржа рассчитывается как доля цены продажи, а не как наценка на себестоимость.
- Все денежные расчёты выполняются через Decimal с округлением до копеек.
- API проверяет принадлежность тендера и позиции текущей компании; расчёт не сохраняется и не изменяет закупочную цену.
- В карточке тендера добавлена форма калькуляции и просмотр трёх сценариев.

## Важные ограничения
- Налоговая сумма вводится пользователем вручную; НДС автоматически не выводится.
- Калькуляция предварительная, не является подтверждённой закупочной себестоимостью и не заменяет бухгалтерский расчёт.
- Результат пока не сохраняется как версия расчёта; для сохранения допущений и истории потребуется отдельная сущность и миграция.
- Поставщики, аналоги и подтверждённые коммерческие предложения ещё не связаны с калькуляцией.
- PostgreSQL/RLS runtime, production-сборка React, браузерный E2E и Docker runtime не выполнены в этой среде.
- Дополнительная проверка: `frontend/src/App.tsx` успешно прошёл TypeScript `transpileModule` синтаксическую проверку (0 синтаксических ошибок). Это не заменяет type-check и production-сборку.
