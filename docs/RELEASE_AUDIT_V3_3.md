# ПОТОК CRM Core v3.3 — аудит готовности релиза

## Назначение версии

v3.3 не объявляется production-релизом. Это контрольная сборка для систематизации технического состояния проекта, проверки цепочки миграций и устранения рассинхронизации версии приложения.

## Проверки, выполненные локально

- Синтаксический разбор Python-файлов.
- Проверка цепочки Alembic: уникальность revision, наличие родительских ревизий, один корень и отсутствие ветвления.
- Проверка номера версии FastAPI.
- Проверка подключения ключевых роутеров.
- Проверка наличия явной маркировки демонстрационных показателей в интерфейсе.
- Целевые тесты документов из v3.1/v3.2.

Запуск:

```bash
python tools/release_audit.py
python -m compileall -q app migrations tests
pytest -q tests/test_document_extraction_v3_2.py tests/test_document_download_v3_1.py
```

## Выявленные ограничения и блокирующие задачи

1. **PostgreSQL не проверен в этом окружении.** Полный pytest останавливается при импорте драйвера `psycopg`, которого нет в среде исполнения. Пакет присутствует в `requirements.txt`; это проблема текущего окружения, а не подтверждение работоспособности БД.
2. **Миграции не применялись к реальной БД.** Статическая проверка цепочки не заменяет upgrade/downgrade тесты и проверку ограничений, индексов, триггеров и RLS.
3. **RLS требует интеграционного тестирования.** Нужны отдельные роли PostgreSQL, проверка отсутствия доступа к чужому tenant, включая фоновые задачи и транзакции с повторным использованием соединений.
4. **Интерфейс остаётся демонстрационным.** Навигация в панели не означает наличие полноценных экранов модулей; KPI жёстко заданы и помечены как вымышленные.
5. **Токен в localStorage.** Перед публичным запуском требуется отдельный проект по безопасной cookie/session схеме, CSRF-защите, ротации и отзыву сессий. Простая замена хранения без изменения backend не допускается.
6. **Загрузка документов.** Проверить MIME по содержимому, лимиты потоковой загрузки, антивирусную проверку, атомарность файловой и DB операций, права каталога, backup/restore и гонки при параллельном создании версий.
7. **OCR не реализован.** v3.2 извлекает текстовый слой PDF/DOCX/XLSX; сканированные PDF и изображения не распознаются.
8. **Нет подтверждённого production-развёртывания.** Сервер пользователя не изменялся; DNS, TLS, резервирование и мониторинг CRM не настроены.
9. **Правовая готовность не подтверждена.** До реальных данных российских граждан требуется юридическая проверка схемы по 152-ФЗ, договоров поручения, уведомлений и локализации; сам выбор российского хостинга не гарантирует соответствие всей системы.

## Критерии допуска к пилоту

- Поднять отдельную тестовую PostgreSQL и прогнать все миграции с нуля.
- Прогнать полный pytest после установки зависимостей из lock-файла.
- Пройти tenant-isolation tests для всех API и файловых операций.
- Проверить RBAC матрицу на каждом изменяющем endpoint.
- Проверить конкурентные сценарии резервирования, отгрузки, распределения платежей и версий документов.
- Реализовать сессии, MFA, CSRF, rate limiting, восстановление доступа и аудит административных действий.
- Реализовать полноценные рабочие экраны, убрать демо-метрики из рабочего режима.
- Проверить backup/restore и процедуру обновления/отката.
- Провести независимый security review и юридическую оценку.

## Честный статус

Эта сборка — инженерная контрольная версия для дальнейшей разработки. Она не является готовой CRM для коммерческой эксплуатации и не должна использоваться с реальными персональными или финансовыми данными.
