# ПОТОК CRM Core v0.5

- Устранено дублирование вложенной папки проекта в архиве.
- Исправлена ORM-связь `Membership.user`, используемая API профиля.
- Добавлен серверный RBAC helper с закрытым по умолчанию доступом.
- Добавлена контрольная административная точка, доступная только директору.
- Добавлены тесты перечня ролей и автономный offline QA-инструмент `tools/qa_check.py`.

## Границы v0.5
Это подготовка к полноценному RBAC, не готовая матрица разрешений по каждому действию. Изоляция PostgreSQL RLS, проверка транзакционных операций, MFA, подтверждение почты, лимиты и аудит остаются следующими обязательными задачами. Не развёртывать в интернет.
