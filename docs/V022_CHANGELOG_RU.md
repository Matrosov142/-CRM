# ПОТОК CRM Pilot v0.22 — журнал изменений

## Исправление корректности выхода из системы

- Исправлен сценарий выхода из текущего сеанса: интерфейс проверяет HTTP-ответ сервера и только после подтверждённого отзыва очищает локальное состояние.
- Исправлен сценарий завершения всех сеансов: при ошибке CSRF, сети или сервера интерфейс больше не скрывает рабочее пространство и не сообщает об успешном выходе.
- Добавлены проверки release audit и регрессионный тест контракта интерфейса.

Это исправление не заменяет E2E-проверку в браузере и интеграционные испытания на PostgreSQL.
