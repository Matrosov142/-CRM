# ПОТОК CRM Pilot v0.8

## Изменения
- Токен доступа хранится только в памяти интерфейса; `localStorage` и `sessionStorage` не используются. После обновления страницы требуется повторный вход. Это временное снижение риска, а не замена защищённой HttpOnly-сессии с CSRF-защитой.
- После расчёта доставки интерфейс сохраняет ID расчёта и позволяет выбрать вариант.
- Добавлен экран «Отгрузки»: просмотр отгрузок, плановой и фактической стоимости, ввод фактической суммы и обновление списка.
- Версия API и интерфейса синхронизирована до 0.8.0-pilot.
- Исправлено объявление типа DeliveryHistory с некорректным буквальным `\\n`.

## Проверки
- Python compileall и статический аудит.
- Автономные тесты без PostgreSQL-зависимостей.
- Проверка отсутствия хранения токена в браузерном хранилище.

## Ограничения
- Production-сборка React не выполнена: npm-зависимости отсутствуют в среде.
- PostgreSQL/RLS интеграционные тесты не выполнены.
- `test_operation_controls.py` не собран из-за отсутствующего `psycopg`.
- Авторизация пока Bearer-токеном в памяти, не HttpOnly cookie/session.
- Нет полноценного UI создания отгрузки и интеграционного теста с БД.
- Сборка не является допуском к реальным данным или публичному запуску.
