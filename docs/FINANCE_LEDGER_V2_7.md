# Финансовый реестр v2.7

Добавлен tenant-scoped реестр денежных движений. Поддерживаются поступления (`receipt`) и оплаты (`payment`), черновик, подтверждение и отмена черновика. Только подтверждённые операции включаются в `/api/v1/finance/summary`.

## API
- `POST /api/v1/finance/movements` — создать черновик.
- `GET /api/v1/finance/movements` — список с фильтрами `status`, `kind`.
- `POST /api/v1/finance/movements/{id}/confirm` — подтвердить.
- `POST /api/v1/finance/movements/{id}/cancel` — отменить только черновик с причиной.
- `GET /api/v1/finance/summary` — сводка подтверждённых поступлений/оплат и чистого денежного потока.

Доступ: директор и бухгалтер. Все операции привязаны к компании из активного членства; `company_id` от клиента не принимается. Опциональная ссылка на закупочный заказ проверяется в рамках той же компании. Суммы — RUB, Decimal/Numeric(14,2). Есть RLS и аудит.

## Ограничения
Это внутренний кассовый реестр, не бухгалтерский/налоговый учёт. Пока нет банковской интеграции, счетов-фактур, распределения одного платежа между несколькими обязательствами, автоматического расчёта дебиторской/кредиторской задолженности, сторно подтверждённых операций и привязки к продажным заказам/контрагентам как отдельным сущностям. Подтверждение означает фиксацию факта пользователем, а не банковскую верификацию.
