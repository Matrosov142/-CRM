# Ответы поставщиков и сравнение — Core 1.7

## Назначение
Фиксация входящих предложений поставщиков, проверка человеком, сравнение по позициям запроса и ручной выбор поставщика. Внешняя отправка запросов, почтовая/Telegram-интеграция и OCR не реализованы.

## API
- `POST /api/v1/rfqs/{rfq_id}/offers` — записать ответ одного адресата. Канал: `manual`, `email`, `telegram`, `upload`. Сохраняются исходный текст, реквизиты предложения, сроки, доставка, заявленный НДС и строки. Ответ создаётся со статусом `pending`.
- `GET /api/v1/rfqs/{rfq_id}/offers` — список ответов.
- `POST /api/v1/rfqs/{rfq_id}/offers/{offer_id}/review` — `confirmed` или `rejected`; только подтверждённые ответы участвуют в сравнении.
- `GET /api/v1/rfqs/{rfq_id}/comparison` — сравнение по каждой позиции.
- `POST /api/v1/rfqs/{rfq_id}/selections` — ручной выбор предложения по позиции. Выбор разрешён только для подтверждённого ответа и строки с `specification_match=match`.

## Расчёт
Сумма строки = количество из предложения × цена за единицу. Доставка и явно указанный поставщиком НДС распределяются между строками пропорционально стоимости товаров в ответе. НДС не рассчитывается по ставке и не выводится автоматически: если поставщик не указал сумму НДС, поле остаётся неизвестным. Признак полноты НДС отражается отдельно. Распределение доставки/НДС — управленческое сравнение, не налоговый расчёт.

## Контроль
- Ответ привязан к адресату и запросу в пределах одной компании.
- На одного поставщика — один ответ на запрос (повторное внесение блокируется; исправление следует выполнять отдельным процессом версионирования, пока не реализован).
- Неполные ответы допускаются, чтобы фиксировать частичные предложения.
- Ответ не участвует в сравнении до подтверждения сотрудником.
- Автоматического выбора самого дешёвого предложения нет.
- Нельзя выбрать несовпадающую или не проверенную позицию.
- Все ключевые действия пишутся в журнал аудита.
- Миграция `0011_supplier_offers` включает RLS и составные внешние ключи по компании.

## Ограничения
PostgreSQL-миграция и RLS требуют отдельного запуска на тестовой БД. OCR, извлечение из файлов, интеграции, история версий ответов, автоматическая рассылка и полноценный налоговый учёт отсутствуют.
