# ПОТОК CRM v0.15 — исправление контроля качества

## Изменения
- Исправлен критичный дефект статического аудита: проверки реестра браузерных сеансов и индивидуального отзыва ранее располагались после `sys.exit(0)` и никогда не выполнялись. Теперь они входят в обязательный набор проверок до итогового PASS/FAIL.
- Проверка аудита теперь требует актуальную маркировку интерфейса «ПИЛОТ 0.15».
- Демонстрационный баннер обновлён до версии 0.15; предупреждение о том, что KPI не загружаются из базы, сохранено.
- Реестр блокеров актуализирован: в v0.14 уже есть список сеансов и отзыв выбранного сеанса; ротация refresh-секретов остаётся невыполненной.

## Проверки
- 152 теста в 42 выбранных файлах.
- 122 Python-файла прошли compileall.
- 27 Alembic-ревизий: один корень, нет ветвлений.
- Статический аудит пройден после исправления порядка проверок.
- PostgreSQL/RLS, production-сборка React, браузерный E2E и Docker runtime не запускались из-за отсутствующих зависимостей/среды.

**Статус:** технический пилот, не production-ready.
