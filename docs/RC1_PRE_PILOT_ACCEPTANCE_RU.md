# Контрольный лист допуска ПОТОК CRM к пилоту

Процедуры и формы для оставшихся ворот: [staging](RC1_STAGING_CHECKLIST_RU.md), [backup/restore](RC1_BACKUP_RESTORE_RUNBOOK_RU.md), [бизнес-приёмка](RC1_BUSINESS_ACCEPTANCE_TEMPLATE_RU.md). Они не закрывают ворота без приложенных фактических доказательств и назначенных ответственных.

Актуально на 10 ноября 2026 года. Последний проверенный PR head: `7d8cd2ebbbad63e41d7261af52839c0693c611eb`. Release Gate run [42771942245](https://github.com/Matrosov142/-CRM/actions/runs/42771942245) завершился успешно (5/5 jobs), CI run [42771942185](https://github.com/Matrosov142/-CRM/actions/runs/42771942185) также успешен. На этом head проверены PostgreSQL/RLS, frontend, Chromium E2E и Docker Compose. Локальный preflight ограничен отсутствием pytest, npm, Docker и PostgreSQL.

## Технические проверки этой итерации

- `python -m compileall -q app migrations tests`: прошёл локально, 148 Python-файлов после добавления dashboard API.
- `python tools/release_audit.py`: прошёл локально; аудит требует dashboard API и tenant/status scoping, запрещает фиктивные KPI.
- YAML parse для `ci.yml`, `release-gate.yml`, `compose.pilot.yml`, `compose.postgres-test.yml`: прошёл локально.
- `python tools/qa_release.py`: не прошёл полный тестовый этап в этой среде, поскольку отсутствуют pytest/psycopg и disposable PostgreSQL, npm и Docker. Его отчёт сохраняется отдельно как локальный preflight и больше не заменяет канонический CI QA report.
- Полный Release Gate run 40 на кодовом commit `3be10a4` завершился 5/5 успешно; CI run 83 тоже прошёл. Chromium проверил все четыре счётчика, tenant isolation и роль сотрудника в UI.
