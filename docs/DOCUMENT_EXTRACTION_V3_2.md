# Извлечение текста и подсказки реквизитов — v3.2

Добавлен маршрут `POST /api/v1/documents/{document_id}/versions/{version_id}/extract`.

## Поддержка
- PDF с текстовым слоем через `pypdf` (до 300 страниц).
- DOCX через извлечение текста из `word/document.xml`.
- XLSX через чтение XML листов и shared strings.
- Лимиты офисных архивов: до 300 элементов и до 40 MiB распакованного содержимого.
- Предварительные подсказки: ИНН, КПП, номер документа, дата, суммы-кандидаты, упоминания НДС.
- Поиск точных дубликатов по SHA-256 только внутри текущей компании.

## Безопасность и границы
Маршрут проверяет tenant, связь версии с документом, активность документа, путь внутри каталога компании и SHA-256 до чтения. Результат пишется в аудит. Содержимое не сохраняется повторно и не изменяет оригинал или реквизиты документов.

Это **извлечение текстового слоя, не OCR**. Сканированные PDF и изображения не распознаются и вернут отсутствие извлекаемого текста/неподдерживаемый формат. Поля являются эвристическими кандидатами, могут быть ошибочными и требуют проверки человеком. Автоматическое проведение, изменение договора, создание платежа или бухгалтерской записи отсутствует.
