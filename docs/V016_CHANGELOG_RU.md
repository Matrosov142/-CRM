# ПОТОК CRM Pilot v0.16 — реестр тендеров (первый рабочий контур)

## Что добавлено
- Добавлена сущность тендера с компанией-владельцем, площадкой, номером, заказчиком, предметом, НМЦК в рублях, дедлайном, регионом поставки, ответственным, статусом, перспективностью и заметками.
- Добавлен API `POST/GET /api/v1/tenders`, `GET/PATCH /api/v1/tenders/{id}`.
- Доступ к чтению: директор, специалист по тендерам, закупки, бухгалтерия. Создание/изменение: директор и специалист по тендерам.
- Ответственный сотрудник проверяется на принадлежность той же компании.
- Повтор номера тендера на одной площадке внутри компании блокируется.
- Действия создания и изменения записываются в журнал аудита.
- Миграция 0028 добавляет уникальность, проверки статусов/перспективности, составные внешние ключи и принудительную RLS-политику по `app.tenant_id`.
- Перспективность хранится в трёх уровнях: высокая, средняя, низкая (в API: `high`, `medium`, `low`).

## Ограничения этой версии
- Это базовый реестр тендеров, а не полный процесс участия. Позиции тендера, загрузка/распознавание документов, анализ требований, экономика заявки, чек-лист подачи и результаты ещё предстоит реализовать.
- Автоматическое подключение к B2B-Center и другим площадкам не реализовано. Ручное внесение данных не означает подтверждённую интеграцию.
- Отдельный пользовательский экран тендеров в React ещё не реализован; API и модель готовы к следующему этапу.
- PostgreSQL RLS migration/runtime не проверялись на реальном PostgreSQL в этой среде.
