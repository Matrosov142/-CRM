# ПОТОК CRM Pilot v0.18 — позиции тендера

## Реализовано
- Добавлена сущность позиции тендера: наименование, характеристики, количество (до 3 знаков после запятой), единица измерения, ориентировочная цена за единицу и примечание.
- Добавлена миграция `0029_tender_positions`, связанная с `0028_tender_register`.
- Связь позиции с тендером защищена составным внешним ключом `(company_id, tender_id)`; включены и принудительно применяются PostgreSQL RLS policies.
- Добавлены API: список, создание, изменение и удаление позиции в рамках тендера.
- Все запросы проверяют принадлежность тендера и позиции текущей компании; изменения журналируются.
- Номер строки назначается под блокировкой родительского тендера; уникальность строки закреплена ограничением БД.
- В интерфейсе добавлена карточка выбранного тендера, просмотр и добавление позиций.
- Предварительная сумма рассчитывается как количество × ориентировочная цена. Это оценка, не подтверждённая закупочная себестоимость.

## Ограничения
- Поставщики, аналоги, подтверждённые коммерческие предложения и полная калькуляция себестоимости ещё не связаны с позициями.
- PostgreSQL/RLS runtime, production-сборка React, браузерный E2E и Docker runtime в этой среде не выполнены.
- Данные реальных электронных площадок не импортируются автоматически.
