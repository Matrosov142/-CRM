# ПОТОК CRM Core v3.6

Инженерная сборка с исправленным воспроизводимым QA runner и синхронизацией релизных проверок.

## Что изменено в v3.6

- Исправлена логика исключения тестов, зависящих от PostgreSQL-драйвера.
- `test_operation_controls.py` запускается при наличии `psycopg`; без драйвера корректно исключается из офлайн-прогона.
- `test_postgres_rls_integration.py` запускается только при наличии `psycopg` и двух явно заданных URL тестовых БД.
- Отчёт записывается в `docs/QA_REPORT_V3_6.json`.
- Версия FastAPI, статического аудита и QA runner синхронизирована на `3.6.0`.
- Добавлены контрактные тесты самого QA-контура.

## Проверка, выполненная в текущем окружении

- 96 Python-файлов прошли `compileall`.
- Статический аудит прошёл.
- 102 теста прошли; два файла, требующие `psycopg`/PostgreSQL, исключены по причине отсутствия драйвера.
- Bash-синтаксис локального PostgreSQL QA runner проверен.
- PostgreSQL 16, Alembic upgrade на реальной БД и RLS integration в этом окружении не запускались.

Повторить доступную проверку:

```bash
python tools/qa_release.py
```

Полный тестовый контур с отдельной временной PostgreSQL:

```bash
bash tools/run_postgres_qa.sh
```

Скрипт требует Docker Compose plugin и устанавливает зависимости из `requirements.txt`. Он использует отдельный контейнер `potok-crm-postgres-test`, привязывает порт только к `127.0.0.1:55432` и удаляет только свой контейнер/том при завершении.

## Текущий статус допуска

**Не production-ready.** До пилота обязательны:
1. Успешный полный PostgreSQL/RLS прогон.
2. Исправление замечаний статического и runtime аудита.
3. Проверка tenant isolation на всех API, включая связанные записи и файлы.
4. Безопасная сессия вместо хранения access token в `localStorage`, CSRF-защита.
5. Проверка загрузки файлов, MIME/сигнатур и антивирусное сканирование.
6. Резервное копирование и тест восстановления.
7. Сборка и проверка frontend production bundle.
8. Нагрузочная проверка и анализ журналов.
9. Проверка российского размещения, договоров обработки и требований 152-ФЗ.

Не использовать реальные персональные, коммерческие или финансовые данные до прохождения этих ворот.
