# ПОТОК CRM Pilot v0.24 — журнал изменений

## Исправление релизных регрессионных проверок

- Исправлены устаревшие тестовые ожидания версии, оставшиеся после перехода с v0.22 на v0.23.
- Проверки синхронизации версии API, интерфейса и релизного аудита теперь сверяют актуальную версию v0.24.
- Сохранены функциональные изменения v0.23: связь строк RFQ с позицией тендера и дополнение ORM metadata моделями обработки.
- Обновлены релизные маркеры, журнал и отчёт QA.

## Ограничения

- Исправление четырёх тестовых ожиданий не является исправлением runtime-дефекта бизнес-функций.
- PostgreSQL/RLS runtime, production-сборка React, browser E2E и Docker runtime требуют соответствующей инфраструктуры и не считаются пройденными без запуска.

## Контроль качества

- 195 тестов пройдены в выбранном локальном наборе; PostgreSQL RLS integration исключён из-за отсутствующего psycopg и тестовых ролей/URL.
- 138 Python-файлов прошли compileall; 31 миграция: один корень, без ветвлений.
- SQLAlchemy metadata успешно создаёт 43 таблицы на SQLite in-memory (проверка metadata, не проверка PostgreSQL).
- FastAPI приложение импортируется; зарегистрировано 77 маршрутов.
- React production build не выполнен: нет npm зависимостей/lock-файла, npm registry недоступен из текущей среды.
- Docker runtime и браузерный E2E не выполнены.
