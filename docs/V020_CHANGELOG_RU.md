# ПОТОК CRM Pilot v0.20 — версии расчёта тендерной позиции

## Реализовано
- Сохранение калькуляции как неизменяемого снимка входных параметров и результата.
- Нумерация версий в пределах позиции тендера.
- История расчётов с автором и временем создания.
- PostgreSQL-триггер запрещает UPDATE/DELETE сохранённых версий; позицию с историей нельзя удалить через API.
- Разграничение: сохранение доступно директору и тендерному специалисту; просмотр — разрешённым ролям тендерного процесса.
- Мультитенантная защита: составные внешние ключи, уникальность версии, ENABLE/FORCE RLS.
- В интерфейсе добавлена кнопка сохранения и список истории.

## Ограничения
- PostgreSQL/RLS runtime не проверен в этой среде.
- Полная production-сборка React и браузерный E2E не выполнены.
- Расчёт по-прежнему предварительный: налоги вводятся вручную, НДС автоматически не определяется.
- Коммерческое предложение поставщика пока не является источником автоматического заполнения калькуляции.
