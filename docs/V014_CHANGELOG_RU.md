# ПОТОК CRM v0.14 — журнал изменений

- Добавлена миграция `0027_auth_session_device_metadata`: ограниченные метаданные User-Agent для браузерных сеансов.
- Добавлен API `GET /api/v1/auth/session/sessions`: показывает только активные сеансы текущего пользователя, без токенов.
- Добавлен API `DELETE /api/v1/auth/session/sessions/{session_id}`: отзывает один сеанс владельца; требует разрешённый Origin и CSRF.
- Добавлен раздел интерфейса «Безопасность» со списком устройств и завершением отдельного сеанса.
- Тип устройства определяется приблизительно по User-Agent; это не надёжная идентификация устройства.
- Автоматическое продление и ротация refresh-секретов пока не реализованы.

## Ограничения проверки

Релизный QA запускается отдельно. PostgreSQL/RLS, E2E браузер, production-сборка React и Docker требуют соответствующей среды и не считаются пройденными без фактического запуска.

- Синтаксически проверено 122 Python-файла.
