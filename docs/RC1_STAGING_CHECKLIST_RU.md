# Чеклист тестового контура RC1

**Цель:** подготовить ограниченный staging, максимально похожий на планируемое размещение, для тестирования только на синтетических данных. Этот чеклист не является разрешением на production deployment.

**Текущая готовность:** шаблон подготовлен; целевой сервер, домен, TLS, хранилище секретов и ответственные не предоставлены. Все контрольные строки ниже имеют статус `OPEN` до внесения доказательства.

## Обязательные ограничения

- Использовать только синтетические данные. Не копировать production backup, клиентские документы, персональные или финансовые данные.
- Не размещать секреты в Git, CI logs, issue или этом чеклисте. Файлы `.env.pilot`/staging держать вне репозитория с минимальными правами.
- Не публиковать PostgreSQL или административные порты в интернет. Не использовать production DNS/сертификаты или реальные интеграционные ключи.
- Staging должен быть отдельной средой с отдельными базой, файлами, ключами и backup-хранилищем.

## Условие допуска к ограниченному тесту

Перед выдачей доступа должны быть закрыты TLS/сеть/секреты/backup, формально согласованы синтетический scope, ответственные и план реагирования. Независимый pentest, бизнес-подпись и юридическое заключение должны быть приложены либо явно оформлены как принятые остаточные риски уполномоченным владельцем релиза. Пока этого нет, решение — **NO-GO для внешнего пилота**. CI Release Gate не подтверждает состояние конкретного staging сервера.
