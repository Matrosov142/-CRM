# v2.6 — финансовые движения (базовый расчётный слой)

## Назначение
Подготовлены проверяемые правила учёта поступлений и оплат. Все суммы — RUB, тип Decimal, денежное округление до 2 знаков.

## Правила
- Виды движения: `receipt` (поступление) и `payment` (оплата).
- Статусы: `draft`, `confirmed`, `cancelled`.
- В денежный поток включаются только подтверждённые движения.
- Черновики и отменённые операции отображаются отдельно и не меняют подтверждённый денежный поток.
- Частичное погашение рассчитывается отдельно по конкретному обязательству.
- Переплата не маскируется отрицательным остатком, а отклоняется с ошибкой.

## API Python
- `CashMovement`
- `summarize_cash_movements`
- `outstanding_amount`

## Ограничения
Это пока расчётный слой в памяти, а не полноценный финансовый реестр CRM. Нет ORM-моделей, миграции, REST API, связи с заказами/контрагентами, банковской выписки, импорта платежей, подтверждения бухгалтером, автоматического расчёта дебиторской/кредиторской задолженности по всем договорам и сверки с 1С. Нельзя использовать его как бухгалтерский или налоговый учёт. Следующий этап — постоянное хранение, tenant-RLS, права бухгалтера/директора, аудит и API.
