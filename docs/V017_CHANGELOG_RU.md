# ПОТОК CRM Pilot 0.17

## Реестр тендеров — первый связанный экран
- Добавлен русскоязычный экран ручного реестра тендеров.
- Экран загружает список через `GET /api/v1/tenders` и создаёт записи через `POST /api/v1/tenders`.
- Используются cookie-сессия и CSRF-заголовок; bearer-токены в браузерное хранилище не помещаются.
- Поля: площадка, номер, заказчик, предмет закупки, НМЦК в рублях, срок подачи, регион, перспективность и примечание.
- Явно указано, что автоматические подключения к ЭТП пока не реализованы.

## Надёжность API
- Добавлена обработка конкурентного конфликта уникальности тендера: HTTP 409 вместо необработанной ошибки сервера.
- Пустые после очистки пробелов обязательные поля отклоняются.
- Добавлены статические регрессионные проверки подключения экрана, CSRF и синхронизации версий.

## Ограничения
- Интерфейс ещё не прошёл production-сборку и браузерный E2E.
- PostgreSQL/RLS runtime-тесты не запускались.
- Список тендеров ограничен первыми 500 записями; серверная пагинация — отдельная задача.
- Это пилот, не production-ready релиз.
