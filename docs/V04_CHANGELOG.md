# Изменения v0.4

1. Bootstrap-регистрация отключена по умолчанию.
2. Добавлена роль членства (`director`) и миграция.
3. Вход при нескольких членствах требует выбора компании.
4. Добавлен endpoint текущего пользователя.
5. CORS вынесен в конфигурацию.
6. Членство и активность пользователя перепроверяются в БД на каждом защищённом запросе.

Роль в токене и поле `memberships.role` пока не заменяют полноценную систему RBAC.
